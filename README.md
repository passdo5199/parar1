# Random Data Generator

Простой проект на Python для генерации случайных данных (имён и адресов) с использованием библиотеки **Faker**.

## Что делает проект

- Генерирует случайное имя (русская локализация).
- Генерирует случайный почтовый адрес.
- Выводит результат в консоль.
